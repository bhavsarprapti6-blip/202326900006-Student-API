# Student CRUD API

This project is a Student CRUD API built using FastAPI.

## Project Description

The Student CRUD API allows users to create, read, update, and delete student records.

The project uses an in-memory data structure and does not require a database.

## Technologies Used

- Python
- FastAPI
- Pydantic
- Uvicorn
